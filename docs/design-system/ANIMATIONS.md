# CINARAI Design System — Animations

Dokumen ini mencatat pola animasi yang sesuai dengan blueprint visual dashboard siswa.

## Prinsip animasi

- Animasi harus halus, ringan, dan tidak mengganggu pengalaman mobile.
- Gunakan transisi singkat untuk interaksi tombol, kartu, dan tab.
- Hindari animasi berlebihan yang membuat antarmuka terasa berat.

## Rekomendasi timing

- Hover/press state: 150ms
- Entry/transition kartu: 200ms
- Bottom navigation switch: 250ms
- Progress state update: 300ms

## Efek visual

- Fade in ringan pada kartu baru
- Scale kecil pada tombol saat ditekan
- Slide halus antar tab atau halaman utama
- Transition warna lembut untuk state aktif

## Pedoman penggunaan

- Semua animasi harus terasa modern dan responsif.
- Animasi dipakai untuk memperjelas perubahan state, bukan sebagai dekorasi utama.
