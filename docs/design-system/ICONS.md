# CINARAI Design System — Icons

Dokumen ini menyesuaikan bentuk dan ukuran ikon yang terlihat pada blueprint dashboard siswa.

## Ukuran icon

- Icon menu/navigation: 24px
- Icon aksi utama: 20px
- Icon pendukung dalam kartu: 18px
- Icon kecil untuk badge/status: 16px

## Ukuran avatar

- Avatar kecil: 32px
- Avatar standar: 40px
- Avatar besar: 56px

## Pedoman penggunaan icon

- Ikon harus memiliki stroke yang jelas dan terlihat modern.
- Gunakan ikon yang konsisten di seluruh halaman.
- Ikon pada tombol utama harus lebih menonjol dibanding ikon pendukung.
- Avatar profil dan pengguna sebaiknya selalu proporsional terhadap ruang kartu.
