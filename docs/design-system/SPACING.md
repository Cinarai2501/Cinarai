# CINARAI Design System — Spacing

Dokumen ini mencatat sistem jarak yang konsisten dengan blueprint visual Dashboard Siswa. Semua nilai disusun untuk mendukung layout mobile-first.

## Grid spacing

| Token | Nilai |
| --- | ---: |
| XS | 4px |
| SM | 8px |
| MD | 12px |
| LG | 16px |
| XL | 20px |
| XXL | 24px |
| 3XL | 32px |
| 4XL | 40px |

## Padding

- Page padding: 16px
- Card padding: 16px
- Section padding: 12px
- List item padding: 12px

## Margin

- Antar section: 16px
- Antar kartu: 12px
- Antar elemen dalam kartu: 8px

## Radius card

- Radius card: 16px
- Radius button: 12px
- Radius badge/pill: 999px

## Shadow

- Shadow ringan: 0 4px 12px rgba(0, 0, 0, 0.08)
- Shadow kartu: 0 8px 24px rgba(0, 0, 0, 0.10)
- Shadow hover: 0 10px 28px rgba(0, 0, 0, 0.14)

## Tinggi elemen penting

- Tinggi button utama: 48px
- Tinggi button kecil: 40px
- Tinggi bottom navigation: 72px
- Tinggi progress bar: 8px
