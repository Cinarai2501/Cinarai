# CINARAI UI Blueprint

Folder ini merupakan referensi resmi seluruh tampilan Dashboard Siswa.

Seluruh implementasi UI Dashboard harus mengacu pada blueprint yang terdapat pada folder ini.

Blueprint yang digunakan:

- dashboard-blueprint.png
- home-blueprint.png
- komik-blueprint.png
- ai-tutor-blueprint.png
- kuis-blueprint.png
- profil-blueprint.png

Aturan implementasi:

- Blueprint adalah referensi utama UI.
- Jangan membuat desain berdasarkan asumsi sendiri.
- Semua halaman harus mengikuti layout mobile-first.
- Gunakan desain modern seperti aplikasi Android, bukan website.
- Gunakan komponen yang konsisten di seluruh halaman.

Jangan mengubah:

- Dashboard Guru
- Login
- Register
- Firestore
- Authentication
- Logic aplikasi
- Progress pembelajaran
- Komik 1
- Komik 2
- Komik 3
- Komik 4
- Komik 5

Blueprint hanya digunakan sebagai referensi visual.
