# Dashboard Home Assets

Folder ini berisi seluruh asset grafis untuk halaman Home Dashboard siswa berdasarkan blueprint UI CINARAI.

## Struktur Folder

```text
home/
├── avatars/
├── levels/
├── covers/
├── statistics/
├── badges/
│   ├── komik/
│   └── pembaca/
└── README.md
```

## Penjelasan Folder

### avatars
Berisi avatar siswa.

Contoh:
- avatar-anak.png
- avatar-anak-perempuan.png

### levels
Berisi icon level.

Contoh:
- icon-level-1.png
- icon-level-2.png
- icon-level-3.png
- icon-level-4.png
- icon-level-5.png

### covers
Berisi cover komik yang digunakan pada kartu Continue Learning.

Contoh:
- cover-komik-cinarai.png

### statistics
Berisi icon statistik Dashboard Home.

Contoh:
- icon-total-xp.png
- icon-streak.png
- icon-komik-selesai.png

### badges/komik
Berisi badge pencapaian komik.

Contoh:
- badge-pembaca-pemula.png
- badge-penjelajah-candi.png
- badge-pencari-bentuk.png
- badge-pecinta-belajar.png

### badges/pembaca
Berisi badge level membaca.

Contoh:
- badge-pembaca-aktif.png
- badge-pembaca-terampil.png
- badge-pembaca-hebat.png
- badge-master-pembaca.png

## Aturan Penamaan

- Gunakan huruf kecil.
- Gunakan tanda minus (-) sebagai pemisah.
- Gunakan format PNG.
- Gunakan background transparan jika memungkinkan.
- Jangan menggunakan spasi pada nama file.

Contoh:

- icon-total-xp.png
- badge-master-pembaca.png
- avatar-anak-perempuan.png

## Catatan

- Semua asset harus mengikuti blueprint Dashboard Home CINARAI.
- Jangan mengubah nama file yang sudah digunakan aplikasi.
- Jika menambah asset baru, ikuti struktur folder dan aturan penamaan yang sama.
- README ini hanya sebagai dokumentasi pengembang.
